# Specialist specimen fonts

Noto Serif Tangut and Noto Serif Old Uyghur are subset to the characters shown
in the atlas. Both are by The Noto Project Authors and retain the SIL Open Font
License 1.1.

- Tangut: [source](https://github.com/notofonts/tangut), [notice and license](OFL.txt).
- Old Uyghur: [source](https://github.com/notofonts/old-uyghur), [notice and license](OFL-Old-Uyghur.txt).

The subset procedure and exact source revisions have not been recorded.
